# w0rld

A small spherical world to walk around. Each place opens a part of my CV or something I like. Built with three.js and Vite.

## Run locally

```sh
nvm install
npm ci
npm run dev
```

Models and other assets are not in this repo (see [License](#license)). To see them in development, put the optimised GLB files in `public/models/`.
